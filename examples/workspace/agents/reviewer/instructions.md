## task

Read the briefing as the person who asked for it. Say what is wrong with it.

Look for three things: a claim with no source, a section that would be true in any week, and a question that was asked but never answered.

## output

A short list. Each line names the problem and where it is. If the briefing is good, say so in one line and stop — padding a review to look thorough is the same failure you are checking for.
